## 核心方法论：2026 外贸 B2B 投放新三角

<CardGrid>
  <Card title="1. 素材即定向（Broad）" icon="seti:video">
    放弃靠兴趣词硬圈 B 端的旧习惯。利用前 3 秒视觉贴纸（OCR）与英文 B 端行话口播（ASR），让算法主动过滤 C 端散客、匹配真实采购决策者。
  </Card>
  <Card title="2. 表单加摩擦（Conditional Logic）" icon="approve-check-circle">
    放弃低门槛默认表单。通过 Higher Intent + 条件逻辑在表单内直接拦截个人自用与低 MOQ 提交，并用手打公司官网/邮箱打破陈旧自动填充。
  </Card>
  <Card title="3. 转化回传（CAPI）" icon="rocket">
    用零代码自动化打通“3 秒业务群通知”与“48 小时内有效 B 端打标回传（QualifiedLead）”，以真实后端质量信号驯化广告账户。
  </Card>
  <Card title="4. 科学放量与业务闭环" icon="setting">
    通过国家三梯队隔离、ABO 冷启动赛马提取 Post ID 进 CBO 常青池，配合自动化止损规则与 5 分钟 WhatsApp 破冰承接完成转化。
  </Card>
</CardGrid>
