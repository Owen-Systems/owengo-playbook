## 本章解决的核心痛点

很多外贸账号刚启动时选择“全球投”或“多国大区混投”，结果不到 48 小时，90% 以上的预算都被低价点击地区吃光，真正欧美或中东高客单市场几乎没有曝光。本章通过**国家梯度隔离 + ABO 沙盒赛马 + 版位硬边界 + 统一命名**，确保冷启动测试阶段每一分预算都打在可控靶区内。

---

## 2.1 公共主页（Page）B 端信任背书 5 项清单

在广告起量前，B 端采购点击广告或主页头像时一定会顺手审查 Facebook Page 的真实性与专业度。上线前需完成以下 5 项基础检查（详细核对流程待 V0.2 补齐操作截图）：

1. **品牌视觉一致**：主页头像（Logo）与封面横幅体现真实工厂、产品线或核心应用场景；
2. **实体信息完整**：`About` 栏目补全公司官网、企业邮箱、工厂所在地与主营业务英文简介（避免使用免费个人邮箱）；
3. **近期动态活跃**：至少保留 5~10 条近期的车间实拍、装柜发货、展会或质检贴文，避免“空壳新主页”直接投广告；
4. **联系方式畅通**：绑定可正常接收消息的 WhatsApp Business 或企业邮箱，保持回复状态正常；
5. **评论区基础维护**：及时清理明显水军/无关广告评论，确保高潜采购看到正常的商业问答互动。

## 2.2 国家三梯队拆分法与必排黑名单

:::caution[核心原则：严禁将 Tier 1 / Tier 2 / Tier 3 混在同一广告组]
Meta 竞价系统天然偏向用最低成本（最低 CPM/CPL）花完你的预算。若将高 CPM 欧美国家与低 CPM 发展中国家放在同一个 Ad Set 中，预算会迅速向低成本地区倾斜。**不同梯队必须分广告组（Ad Set）或分广告系列（Campaign）隔离。**
:::

| 梯队划分 | 覆盖国家/地区 | 投放重点与日预算（参考阈值） | 必设排除项与过滤要求 |
| :--- | :--- | :--- | :--- |
| **Tier 1（核心高客单）** | US, CA, GB, AU, NZ | 客户更看重专业度、合规认证与交付稳定性，毛利空间相对更厚。ABO 测试 **参考阈值** `$40~$50/组/天` | 全球或大区混投时**强制排除**：`IN`（印度）、`PK`（巴基斯坦）、`BD`（孟加拉）、`NG`（尼日利亚）、`PH`（菲律宾）、`EG`（埃及） |
| **Tier 2（高潜力溢价）** | 欧洲核心国（德/法/荷/意/西/北欧）、中东 GCC（UAE, KSA）、日韩新 | 中东重工程交付与 WhatsApp 直接沟通；欧洲重环保与合规认证。ABO 测试 **参考阈值** `$25~$35/组/天` | 同步执行上述黑名单排除。投放中东 GCC 时，建议语言锁定 `English (All)` + `Arabic`，过滤南亚劳工群体 |
| **Tier 3（新兴走量）** | 墨西哥、巴西、智利、越南、泰国、马来西亚、中亚 | 适合推标准品、常规现货或招募区域代理，单条线索表观 CPL 相对更低 | 排除低转化岛国及外汇管制严重地区（具体按收款与物流能力增补） |

> 可直接复制的国家代码清单见：[模板 02：国家梯队与必排黑名单清单](/b2b-meta-ads/templates/02-country-tiers-blacklist/)。

## 2.3 冷启动 ABO 沙盒全参数设置

冷启动测试期的目标不是“立刻放量”，而是以可控成本验证**哪一个切角或前 3 秒 Hook 能持续跑出合格 B 端询盘**：

- **Campaign 层级**：
  - 营销目标选择 `Leads`（潜在客户）；
  - **关闭** `Advantage+ Campaign Budget`（即保持 **ABO 广告组预算模式**），避免测试期系统把预算全喂给某一个刚巧产生 1 条低质表单的组。
- **单组素材数**：
  - 每个 Ad Set 严格控制 **3~4 条素材**；
  - 遵循 **“同切角、微差异”** 原则：保持同一核心卖点与目标买家一致，仅改变前 3 秒 Hook 或展示形式（例如：`3 条视频 + 1 组工程轮播图`）。
- **赛马裁决窗口（参考阈值）**：
  - 给予 **48~72 小时**基础学习与观察期；
  - 单条素材消耗达到 **1~1.5 倍目标 CPL** 且 **0 表单**，或 **CTR 低于 0.8%** 时直接关停（参考止损线，需结合品类校准）；
  - 当单组或单条素材跑出 **3~5 个合格 B 端线索** 后，按第 6 章规则提取 `Post ID` 进入 CBO 常青放量池。

## 2.4 受众与版位硬边界

为防止算法在测试期探索出大量低意向 C 端流量，Ad Set 层级需设好以下硬边界：

1. **年龄锁定**：`28 - 65+` 岁（过滤学生群体与非决策年轻消费用户）；
2. **细分兴趣词**：**完全留白（Broad）**，并且**关闭** `Advantage+ detailed targeting`（细分定位扩展）相关开关（若界面出现对应提示），将精准筛人交给第 3 章的前 3 秒素材与第 4 章的条件表单；
3. **语种过滤（中东等地区）**：如投中东 GCC，语言设置锁定 `English (All)` + `Arabic`；
4. **手动版位（Manual Placements）**：仅保留 **Facebook / Instagram 的 Feed（动态）与 Reels（短视频）**；**强制取消勾选 `Audience Network`**（网盟流量往往伴随高误触与大量垃圾点击）。

## 2.5 工业级三层级广告命名规范

命名混乱会导致后期在表格、Make 自动化与周报审计时无法归因“到底是哪个国家、哪个切角、哪个 Hook 带来了成交线索”。全团队建议强制执行以下三层级命名结构：

### 命名结构模板

- **Campaign（广告系列）**：
  ```text
  [产品]_[预算模式]_[地区梯队]_[目标]_[上线年月]
  ```
  - 示例：`Desk_ABO_T1-US_Leads_202611`
  - 示例：`Desk_CBO_T1-Scale_ConvLeads_202612`

- **Ad Set（广告组）**：
  ```text
  [国家代码]_[受众类型]_[年龄段]_[版位]_[切角代码]
  ```
  - 示例：`US_Broad_28-65_FeedReels_ANG1-Factory`

- **Ad（广告）**：
  ```text
  [切角代码]-[格式]-[编号]_[前3秒Hook摘要]_[落地载体]_[PostID状态]
  ```
  - 示例：`ANG2-VID-01_CordlessPneumatic_IF_PostID-982341234`

### 标准缩写字典

| 维度 | 标准代码 | 含义说明 |
| :--- | :--- | :--- |
| **切角代码** | `ANG1-Factory` | 源头工厂实力 / OEM & ODM 定制 |
| **切角代码** | `ANG2-Feature` | 产品微创新 / 高溢价差异化卖点 |
| **切角代码** | `ANG3-Test` | 暴力极限测试 / 商业工程交付背书 |
| **素材格式** | `VID` / `IMG` / `CAR` | 视频（Video）/ 单图（Image）/ 轮播（Carousel） |
| **落地载体** | `IF` / `LP` / `WA` | 即时表单（Instant Form）/ 独立站落地页 / WhatsApp |

> 可用公式与上线前核对清单见：[模板 03：三层级命名生成器](/b2b-meta-ads/templates/03-naming-convention-generator/) 与 [模板 04：新账户上线 12 项自检 Checklist](/b2b-meta-ads/templates/04-launch-preflight-checklist/)。
