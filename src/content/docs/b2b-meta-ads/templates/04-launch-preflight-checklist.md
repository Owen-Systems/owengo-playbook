> 对应章节：[第 2 章：防跑偏基建与冷启动沙盒](/b2b-meta-ads/chapters/02-account-and-sandbox/) ｜ 状态：SOP 已就绪（上线前逐项核对）

发布新广告系列前，请操作手逐一核对以下 12 项红线。任意一项未通过，禁止点击 `Publish`。

| 序号 | 检查项 | 合格标准 |
| :--- | :--- | :--- |
| **01** | **公共主页（Page）背书** | 已补全官网、企业邮箱、工厂介绍与近期至少 5~10 条真实工厂/发货动态，无空壳感 |
| **02** | **国家梯队严格隔离** | Tier 1、Tier 2、Tier 3 分组隔离投放，未出现跨梯队混投抢预算情况 |
| **03** | **黑名单强制排除** | 已排除 `IN, PK, BD, NG, PH, EG`（及按品类需要排除的低质量或汇管受限地区） |
| **04** | **中东/特定区语种锁死** | 若投放中东 GCC，语言设置已锁定 `English (All)` + `Arabic` |
| **05** | **测试期预算模式（ABO）** | Campaign 层级已关闭 `Advantage+ Campaign Budget`，使用 ABO 独立组控预算 |
| **06** | **年龄与 Broad 受众边界** | 年龄锁定 `28 - 65+`；细分兴趣词保持留白（Broad），关闭不必要的人群扩展 |
| **07** | **版位强制剔除网盟** | 仅保留 Facebook / Instagram 的 `Feed` 与 `Reels`，**已取消勾选 `Audience Network`** |
| **08** | **单组素材配比合理** | 严格控制在 `3~4` 条同切角微差异素材（如 `3 视频 + 1 静态/轮播图`） |
| **09** | **素材前 3 秒防 C 端检查** | 顶部 15% 安全区已加注 B2B / MOQ 贴纸，前 5 秒口播含 B 端英文行话 |
| **10** | **条件逻辑表单启用** | 已选用 `Higher Intent`，开启 `Conditional Logic` 并配置 Q1/Q2 `Close Form` 拦截 |
| **11** | **Leads Access 与表格连通** | BM 已授权 Make/Zapier，测试提交一条表单后 3 秒内表格与群机器人均能收到通知 |
| **12** | **三层级标准命名完成** | Campaign / Ad Set / Ad 已严格按照 [模板 03](/b2b-meta-ads/templates/03-naming-convention-generator/) 完成命名 |
