## 1. 核心数据表字段清单（Google Sheets / 飞书多维表格通用）

| 列序号 | 字段名称 | 字段类型 | 填写 / 写入规则 | 核心作用 |
| :---: | :--- | :--- | :--- | :--- |
| **A** | `Meta Lead ID` | **纯文本** | Make 写入 `15~16` 位数字 ID（必须设文本格式，防变成科学计数法） | **唯一归因钥匙**：反向回传 CAPI 必填 |
| **B** | `提交时间` | 日期时间 | ISO 或本地时间 `YYYY-MM-DD HH:mm` | 统计 5 分钟响应与 48h 分级时效 |
| **C** | `广告系列 / 素材来源` | 文本 | 写入 `Campaign / Ad Name` | 对接三层级命名字典审计线索质量 |
| **D** | `客户姓名` | 文本 | 来自预填字段 `Full Name` | 业务员打招呼称呼 |
| **E** | `公司名称` | 文本 | 来自预填字段 `Company Name` | 核对公司背景 |
| **F** | `业务角色 (Q1)` | 文本 | 来自条件表单 Q1 | 判断属于进口商、大卖还是工程商 |
| **G** | `预估采购量 (Q2)` | 文本 | 来自条件表单 Q2 | 判断订单体量，匹配报价策略 |
| **H** | `采购产品线 (Q3)` | 文本 | 来自条件表单 Q3 | 分配对应产品图册 |
| **I** | `官网 / LinkedIn / 工作邮箱 (Q4)` | 文本 | 来自手打简答题 Q4 | 3 分钟快速背调核心入口 |
| **J** | `WhatsApp 电话` | **文本** | **Make 写入时前加英文单引号 `'`**（例：`'+14155550199`） | **防止 `+` 号被表格识别为公式报错** |
| **K** | `预填邮箱` | 文本 | 来自预填字段 `Email` | 备选联络 & CAPI 匹配参数 |
| **L** | `一键 WhatsApp` | **公式列** | 见下方 `REGEXREPLACE` 公式 | 业务员一键点击直跳聊天窗口 |
| **M** | `线索质量状态` | 单选 | `待跟进` / `有效B端(Qualified)` / `已发报价` / `无效` | **反向 CAPI 回传触发开关** |
| **N** | `CAPI 回传状态` | 文本/单选 | 默认空或 `未回传`；回传后 Make 回写 `已回传-日期` | **防重复回传锁** |

## 2. 一键 WhatsApp 清洗公式（直接复制）

假设 `J` 列（第 10 列）存放经过单引号保护的原始电话号码（可能带有 `+`、空格、括号或 `-`），在 `L2` 填入以下公式：

### Google Sheets 版本
```text
=IF(J2="", "", "https://wa.me/" & REGEXREPLACE(TO_TEXT(J2), "[^0-9]", ""))
```

### 飞书多维表格参考逻辑
- 若使用飞书多维表格公式字段，使用等效文本替换逻辑移除 `+`、空格与 `-`，再与 `"https://wa.me/"` 拼接；或直接由 Make 在写入表格前用 `replace(phone, /\D/g, "")` 预先生成纯数字链接写入该列，稳定性更高。
