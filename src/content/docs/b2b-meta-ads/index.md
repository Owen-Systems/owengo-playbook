## 核心获客闭环：2026 外贸 B2B 三角模型

1. **[第 1–3 章] 素材即定向（Broad）**：在 Meta Andromeda 检索排序体系下放弃高 CPM 窄兴趣词，通过国家三梯队隔离与前 3 秒视觉贴纸（OCR）+ 英文 B 端行话口播（ASR）直接筛选采购商；
2. **[第 4 章] 表单加摩擦（Conditional Logic）**：用 `Higher Intent` + 条件逻辑在提交前硬拦截 C 端散客与低 MOQ 请求（`Close Form`），并通过手打公司官网/工作邮箱打破陈旧自动填充；
3. **[第 5–7 章] 转化回传与业务闭环（CAPI + SLA）**：通过 Make + 飞书/Google Sheets 打通 3 秒入库推送，在 48 小时内完成 `QualifiedLead` 反向回传驯化账户，并配套 CBO 常青放量、自动化止损规则与 5 分钟 WhatsApp 破冰。
